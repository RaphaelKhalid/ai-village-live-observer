# AI Village Live Observer

Live Cloudflare Worker and frontend for the AI Village observer, including Open Chat, Main Village, and Swarm Village views.

Live site: https://ai-village-live-observer.raphaelbahadurkhan.workers.dev/

## Local development

```bash
npm install
npm run build
npm run dev
```

The observer reads the upstream village feeds through the Worker API. The UI defaults to light mode and includes the conversation relationship network view.
